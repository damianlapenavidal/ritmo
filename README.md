# Ritmo

The web app for my training and nutrition system. This repo holds only code and **made-up demo data**.
My real logs live in a separate private repo; the app reads and writes them through the GitHub API with a fine-grained token stored only in the browser.

Live: https://damianlapenavidal.github.io/ritmo/

Workouts: today's plan with last time and a suggested load for each lift, exercise photos and steps, coach-approved swaps, and a program library you can switch between. Exercise data: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (public domain), see [THIRD_PARTY.md](THIRD_PARTY.md).

Editing: see CLAUDE.md (how it works, rules, local preview) and DESIGN.md (tokens and components).
